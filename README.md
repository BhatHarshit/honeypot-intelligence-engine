## Problem Statement

Organizations handling personal data face significant compliance challenges 
under India's DPDP Act 2023. Manual audits are slow, error-prone, and 
impossible at scale. Data Privacy Officers need an automated system that 
continuously monitors datasets, detects PII exposure risks, verifies consent, 
and generates actionable compliance reports — before regulators do.

---

## What This System Does

This platform goes beyond a simple PII detector. It is a full Privacy 
Engineering Platform that demonstrates understanding of data engineering, 
AI/ML, data governance, privacy operations, compliance automation, and 
risk assessment — built specifically around healthcare data privacy.
